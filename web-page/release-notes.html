Capture 2026.10.3 · macOS

Link to this release ↗

Transparent sharing and better text boxes

Copy individual annotations into other apps, preserve transparency, and edit text boxes where you place them.

01

Copy and export

  • Copy a selected annotation with Command-C. Arrows, shapes, and text boxes copy as transparent PNG images for pasting into apps such as Keynote. Edit → Copy Annotation does the same. Pasted objects are images, not native editable shapes.
  • Keep full-image and text copying. Shift-Command-C and Copy Image copy the full canvas. Command-C still copies selected text while editing.
  • PNG is the default. Copy Image, Export, and Save As preserve transparency, including empty areas beyond the original image.
  • JPEG backgrounds match the image. When saving as JPEG, transparent areas use the average visible image color instead of black. Save retains an existing file’s format.
02

Text and window sizing

  • Centered text. Text is centered horizontally and vertically while editing and in the final image.
  • Wider starting boxes. New text boxes extend toward the canvas’s right edge. Their height grows as text wraps, and you can resize them manually.
  • Edit outside the original image. Double-click a moved text box to edit it in place without snapping back inside the image.
  • More room on launch. New windows use 70% of the screen’s usable width and height, subject to the minimum window size.

Capture 2026.9.27 · macOS

Link to this release ↗

Keyboard shortcuts and annotation controls

Tool and size shortcuts, visible shortcut hints, annotation duplication, and fixes to Size selection.

⌥ A Arrow ⌥ 1–5 XS through XL ⌘ D Duplicate annotation
01

Toolbar shortcuts

  • Option shortcuts for tools. Use Option-A for Arrow, Option-T for Text, and Option-E for Ellipse. Option-R selects Rectangle, Option-B selects Blur, and Option-C selects Crop.
  • Option-1 through Option-5 select sizes. The keys map to XS, S, M, L, and XL, including while editing text.
  • Hold Option to see the keys. Bubbles show tool and size shortcuts, Esc for Select, and full Command shortcuts such as ⌘= for Zoom In.
  • Keep text when switching tools. Tool shortcuts commit active text. Esc commits the text and returns to Select.
02

Duplication and size selection

  • Duplicate selected annotations with Command-D. The copy keeps the original style, appears slightly offset, and can be edited independently. Duplication supports undo and redo.
  • Size matches the annotation. New arrows and shapes start at the displayed M size. Selecting an annotation or undoing a size change updates the Size control.
  • Compact toolbar layout. Size appears before Color and Text Background. Shortcut bubbles do not increase the toolbar height.
03

About Capture

  • App version and build number. Capture → About Capture shows the version, build number, and copyright. Versions use the release date in year.month.day format.

Capture for macOS

Canvas and text annotation updates

Changes: multiple canvas windows, clipboard shortcuts, text background controls, and expanded canvas output.

⌘ V Paste an image ⌘ N New canvas ⌘ W Close canvas
01

Clipboard and windows

  • Command-V pastes clipboard images. While editing a text annotation, it pastes text.
  • Multiple canvas windows. File → New Canvas opens an independent window. Each canvas keeps its own image, annotations, undo history, and save destination.
  • Window-specific shortcuts and save prompts. Keyboard shortcuts act on the canvas you’re using. Closing a window or quitting checks for unsaved edits, and cancelling keeps your work available.
02

Text annotations

  • Background colour and opacity. New text starts with a black background at 50% opacity. The Text Background menu lets you choose a colour and 0%, 25%, 50%, 75%, or 100% opacity. Changes support undo and redo.
  • Click outside to select. Clicking outside a text box commits your text and switches to Select. It no longer creates another box. Choose Text again when you want to add a new annotation.
  • Bounded text layout. While you type, text wraps within the box and automatic growth stays inside the image. Longer content remains scrollable while editing when it reaches the height limit.
  • Resize handles and zoom. Visible corner and edge handles work even beyond the original image boundary. Text size, padding, and backgrounds stay consistent between editing and the finished result as you zoom.
03

Canvas bounds and output

  • Unrestricted Select-tool transforms. Use Select to move or resize text, shapes, and arrows outside the image. Drawing new shapes and typing text remain constrained to the original image.
  • Automatic canvas expansion. Extra space appears in white, and Fit includes the expanded area. Moving annotations back, deleting them, or undoing an edit adjusts the canvas bounds again.
  • Expanded copy, save, and export. Copy, save, and export include annotations beyond the original image, including their stroke widths. Content is no longer cut off just because it crossed the old canvas edge.
